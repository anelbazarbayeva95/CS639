# CS639
Mobile App Development

This repository is created for CS-639: Mobile App Development at Pace University. It contains all Android projects developed during the Fall 2025 semester.
The repository serves as both a learning archive and a portfolio of Android applications, ranging from beginner-level exercises to more advanced projects.

# Lesson 1
This folder contains:
- **lesson1.kts** — Kotlin basics practice file with variables, data types, and simple functions.  
- **Screenshots** — quiz results and earned badge for Lesson 1.

# Lesson 2
This folder contains:
- **lesson2.kts** — Kotlin practice file with classes, constructors, and object examples.  
- **Screenshots** — quiz results and earned badge for Lesson 2.

# Lesson 3
This folder contains:

- **Screenshots** — quiz results and earned badge for Lesson 3.
