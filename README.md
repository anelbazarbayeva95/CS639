# CS639
Mobile App Development

This repository is created for CS-639: Mobile App Development at Pace University. It contains all Android projects developed during the Fall 2025 semester.
The repository serves as both a learning archive and a portfolio of Android applications, ranging from beginner-level exercises to more advanced projects.

# AboutMe
This folder contains:
- **AboutMe app** — Android project written in Java with multiple fragments, navigation, and user information (biography, contact information, hobbies)  
- **aboutMeAnel.apk** — compiled APK ready to install on a device or emulator.  
- **Screenshots** — images of the app interface.

# BusinessCard
This folder contains:
- **BusinessCard.apk** — compiled APK version of the Business Card app.  
- **Screenshot_1.png** — preview image showing the final layout.  
- **Summary:** A Jetpack Compose app that displays a digital business card with name, title, contact information, and themed background.  
- **Reference:** [Android Basics in Compose - Unit 1, Pathway 3 Codelab](https://developer.android.com/courses/pathways/android-basics-compose-unit-1-pathway-3#codelab-https://developer.android.com/codelabs/basic-android-kotlin-compose-text-composables)

# CircleApp
This folder contains:
- **CircleApp.apk** — compiled APK version of the CircleApp ready to install on a device or emulator.  
- **CircleAppVideo.mov** — short demo video showing app usage and correct calculation flow.  
- **Screenshot_1.png – Screenshot_5.png** — screenshots showing the user interface, color palette, and result output.  
- **Summary:** **CircleApp** is an Android application built in **Kotlin** that computes the **area of a circle** based on a user-entered radius.

# MarsPhotos
This folder contains:
- **MarsPhotos.apk** — compiled APK version of the Mars Photos app.
- **Screenshot_1.** – Screenshot_3.png — images showing the app interface and successfully retrieved photos.
- **Summary:** An Android app built with Kotlin and Jetpack Compose that retrieves and displays photos from NASA’s Mars API using Retrofit and Kotlin serialization.
- **Reference:** [Android Basics in Compose - Unit 5, Pathway 1: Getting Data from the Internet](https://developer.android.com/courses/pathways/android-basics-compose-unit-5-pathway-1?continue=https%3A%2F%2Fdeveloper.android.com%2Fcourses%2Fpathways%2Fandroid-development-with-kotlin-11%23codelab-%2Fcodelabs%2Fkotlin-android-training-internet-data)

# RaceTrack
This folder contains:
- **RaceTrack.apk** — compiled APK version of the Race Tracker app.  
- **Screenshot_1.png – Screenshot_4.png** — four images showing the app interface and race progress.  
- **Summary:** An Android app built with Kotlin and coroutines to simulate two players running a race concurrently.  
  The app demonstrates coroutine usage for concurrent tasks and responsive UI updates in Jetpack Compose.  
- **Reference:** [Android Basics in Compose - Unit 5, Pathway 1: Getting Data from the Internet](https://developer.android.com/courses/pathways/android-basics-compose-unit-5-pathway-1?continue=https%3A%2F%2Fdeveloper.android.com%2Fcourses%2Fpathways%2Fandroid-development-with-kotlin-11%23codelab-%2Fcodelabs%2Fkotlin-android-training-internet-data)
