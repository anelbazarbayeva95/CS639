# Add a Map to Android App
This folder contains:
- **Add a Map to Android App** — Android project built with Kotlin and Jetpack Compose, integrating Google Maps using the Maps Compose library.
- **Add a map to Android app.** — compiled APK ready to install on an Android device or emulator.
- **Screenshots** — UI images demonstrating the map screen and Google Developers Achievement screenshot. 
- **Reference:** [Google Codelab — Add a Map to your Android App using Jetpack Compose](https://developers.google.com/codelabs/maps-platform/maps-platform-101-compose?hl=en#2)
